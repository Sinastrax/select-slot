# more. slot. feature parity tracker

This tracks the select.slot-specific behavior intended for the separate UnsloT-based more.slot branch. Test 5 was not feature-complete. Test 6 was an incomplete evaluation build and has been withdrawn after update and installation failures; the entries below describe that failed candidate, not a supported or verified build. UnsloT already has its own implementations of several general Slot features; those count as inherited only after their behavior is checked against the maintainer's known-good select.slot behavior.

## Release gate

Do not call a more.slot build feature-complete or feature-parity verified until each row is implemented or its upstream UnsloT equivalent is inspected and marked verified. Do not publish another OTA until the requested feature set is present, its complete package and update/install/rollback path pass CI, and applicable device testing is complete. A successful package check is separate from hardware confirmation. Stable select.slot releases and their OTA feed remain independent.

## Current status

Test 6 is withdrawn. Its candidate changes are not confirmed as a working implementation, and the failed update/install path makes it unsuitable for further installation testing. The Test 5 manifest remains only as the prior feed pointer; it is not designated as a recovery image. Full feature parity, a reliable OTA path, and device validation remain outstanding.
