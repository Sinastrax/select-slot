# more. slot. feature parity tracker

This tracks the select.slot-specific behavior that must be carried into the separate UnsloT-based more.slot branch. Test 5 was not feature-complete. Test 6 is the current port candidate, and is not ready for publication while rows remain incomplete. UnsloT already has its own implementations of several general Slot features; those count as inherited only after their behavior is checked against the maintainer's known-good select.slot behavior.

## Release gate

Do not call a more.slot build complete or publish it as a feature-parity update until each row is implemented or its upstream UnsloT equivalent is inspected and marked verified. A successful package/OTA check is separate from hardware confirmation. Stable select.slot releases and their OTA feed remain independent.

## Current work

The keyboard, Authentic display, and GB model selector ports are in the candidate feature branch. Game Gear research now matches SlotPlus Ultra’s core and art conventions; Gearsystem is the default with PicoDrive retained as an alternate. Its cartridge bay now has a saved per-user choice and uses SlotPlus Ultra's dedicated Game Gear artwork. The GB model selector stores separate mGBA and Gambatte choices and routes core options based on model; build and behavior verification remain pending. The compositor now turns frame blending off while fast-forwarding, and Authentic reflection can be switched independently from color correction. Gambatte palette values and correction now use that core's own option names. The keyboard behavior is: a first Shift press highlights the key and applies to one typed character, a second consecutive press locks Caps, and the next press unlocks it. The on-screen key changes with the lock state. The feature PR build checks the current port and rebuilds the accepted mGBA core; no OTA is published from this branch. The remaining parity work is still release-blocking.
