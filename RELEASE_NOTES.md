# Custom slot. Ver. 1.15.3-custom.1

## Changes since Ver. 1.15.3-rgsp.3

- **New project identity:** release titles now use **Custom slot. Ver. [version]**, without device-specific branding.
- **New version suffix:** releases use `-custom.N` rather than `-rgsp.N`.
- **Update compatibility:** existing installations running `-rgsp.N` can upgrade directly to `-custom.N` through the built-in updater.

The complete firmware package is unchanged in functionality except for version and updater compatibility. See the [front page](README.md) for the full feature overview.
