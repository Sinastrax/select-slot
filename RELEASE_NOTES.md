# select. slot. 1.16.0 Ver. 22

## Changes since select. slot. 1.16.0 Ver. 21

- **Wi-Fi remains available when removing a cartridge.** During the `Ejecting` phase, a cartridge is technically still considered seated. Previously, that could accidentally invoke the game-only radio shutdown logic during the return animation. The corrected ejection path now retains an already-held radio even when DHCP or Wi-Fi association briefly drops, and begins reconnecting to saved networks when it was deliberately idle during gameplay. Explicit **Wi-Fi Off**, sleep, power-off, and link-play restrictions are unchanged.
- **Light-theme menu status is legible.** The top-left battery percentage and top-right clock are now rasterized separately with the same light HUD ink as the top-corner battery outline. They no longer reuse dark light-theme shelf-footer text against a dark menu background. This covers both the shelf quick menu and the in-game quick-menu corners. Battery display preferences and the normal shelf footer remain unchanged.
- **GBA scaling is available on 720×480 screens.** A 240×160 GBA image at 3× fills a 720×480 panel exactly. Previously, Fit, Integer, and Full Screen all produced the same image, so Slot automatically hid Scale. The **Integer** choice now provides a genuine, centered **2× (480×320)** GBA image on exactly 720×480 screens; **Fit** retains the existing native-size 3× (720×480) picture. The GBA Scale choice is stored in the existing `scale_gba` setting. All other panels, GB/GBC scaling, and shader/color pipelines are unchanged.
- **Regression coverage:** tests check the Wi-Fi service stays held when removing a cartridge during an unstable connection, deliberate Wi-Fi Off still works, the actual top-corner clock/battery textures are drawn in a light-theme quick menu, and the GBA 2× and 3× positions are distinct.

**Scope:** H700 Anbernic firmware only. The tested and user-approved GB/GBC Pocket, SGB, and GBA Authentic shader/color changes, original GBA/GBA SP bezel choice, OTA display branding, archive/checksum security and Miyoo firmware are retained without alteration. Physical device verification is still required.
