# Custom slot. Ver. 1.15.3.3

## Changes since Ver. 1.15.3.2

- **Resume on Power On:** Turning the option off now starts on the game shelf instead of launching the previously played game.
- The previously played game remains selected on the shelf.
- **Resume on Insert** remains independent and continues to control whether manually launching a game loads its saved state.

Firmware tag: `v1.15.3-rgsp.3`. The technical tag is retained for compatibility with already installed online updaters.
